DMapFactory Help > Spreadsheet Mode

Spreadsheet Mode (Wide Format)

Multivariable time-series tabular representation with vertical headers and color-filled boolean indicators

Wide Format Architecture (RF-GRD-01..10)

The primary view displays data in Wide Format. Unlike narrow row-based logging where each record represents a single isolated variable event, each row represents an exact point in time (timestamp) and each column corresponds to a monitored variable, offering a comprehensive snapshot of entire machine lines simultaneously.

Color-Coded Boolean Signals

To enable rapid operator diagnosis of discrete sensors, interlocks, and state alarms, digital variables are rendered with solid color-filled blocks instead of plain numbers (0 or 1):

  • Bright Green: indicates True / Logic High / Active State.
  • Muted Dark Gray: indicates False / Logic Low / Inactive State.

Vertical Column Headers

When tracking dozens of tags, long horizontal headers consume excessive screen space. Check the Vertical column headers option on the spreadsheet toolbar to rotate text 90 degrees.

Header Row Height Adjustment

When headers are oriented vertically, customize row height to ensure full label visibility:

  • Buttons − and +: decrease or increase row height in 20-pixel increments.
  • Button ↕ Auto: automatically calculates the optimal header height based on the longest tag alias.
  • Interactive Mouse Dragging: hover over the bottom border of the column header and drag up or down to set any desired height.

Auto-Fit Column Widths (↔ Auto-fit widths)

The auto-fit button re-evaluates the required width for every column, taking into account both header orientation (vertical or horizontal) and cell data contents to eliminate wasted space.

Precise Tag Removal in Spreadsheet

To remove a specific variable from acquisition without disturbing other columns:

  1. Right-Click Column Header: right-click any tag header to open the contextual menu and select 🗑 Delete tag '...' from collection.
  2. Keyboard Delete Key: click any cell or header in the desired column and press Delete.
  3. Toolbar Button: clicking any cell dynamically updates the main toolbar button to Delete tag (<Alias>).

Smart Auto-Scroll Pause (FN-04)

When analyzing high-frequency real-time signals, continuous auto-scrolling can interfere with inspecting previous rows. DMapFactory features intelligent scroll detection:

  • Automatic Pause on Scroll Up: scrolling up manually to inspect earlier records temporarily suspends automatic scrolling, locking the view on the current row under inspection without clearing the checkbox.
  • Smooth Resumption: scrolling back to the bottom or re-checking the Auto-scroll checkbox immediately resumes live tracking.

Context Menu & Chart ↔ Spreadsheet Cross-Synchronization

Right-clicking any cell or row in the spreadsheet opens a contextual menu with productivity and diagnostics tools:

Action Description
📈 Focus timestamp on Chart (Cursor A) Instantly synchronizes view with the trend chart. Positions Cursor A at the exact timestamp of the selected row for waveform examination.
🚩 Insert marker on this row... Adds a custom text session marker associated with the exact timestamp of the selected row.
⚙ Set as machine cycle trigger (Available on boolean columns) Assigns the clicked boolean variable as the transition source for automated machine cycle calculation.
📋 Copy Row (TSV - Excel Format) Copies the full row in tab-separated format, ready to paste directly into Microsoft Excel, Google Sheets, or text editors (Ctrl+C).
📋 Copy Cell Value Copies the discrete value of the clicked variable.
⏱ Copy Row Timestamp Copies the high-precision timestamp string (yyyy-MM-dd HH:mm:ss.fff).

Additional Spreadsheet Controls

  • Sky-Blue Row Highlight: selected rows feature an elegant sky-blue border (#00B4F0) that keeps all cell values completely legible.
  • Auto-scroll: keeps the grid pinned to newly arriving real-time samples.
  • Sampling Rate & Modes: select intervals between 10 ms and 1000 ms from the top toolbar, toggling between Subscription and Polling modes.
  • Continuous Sampling (1 s): forces a complete row log every 1 second, even when variables experience no value changes.
  • Group Same Timestamp (P3): bundles simultaneous tag transitions into a single unified row.
