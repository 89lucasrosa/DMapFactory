Keyboard Shortcuts & Diagnostics

Productivity hotkeys, fast commands, and acquisition health monitoring

Global Keyboard Shortcuts Reference

Key / Shortcut Context Action Triggered
F1 Any window / control Opens Context-Sensitive Help on the exact topic for the active module.
F5 Main Window Toggles between Online (active sampling) and Offline (paused).
Ctrl + N Main Window Creates a New Project (.dmproj).
Ctrl + O Main Window Opens an Existing Project from disk.
Ctrl + S Main Window Saves the Current Project with all connections and sampling parameters.
Ctrl + Shift + S Main Window Saves the Project As... with a new filename.
Ctrl + Shift + O Main Window Opens a Recorded Session (.csv or .session.json) restoring timeline and markers.
Ctrl + E Main Window Exports the Spreadsheet to Excel (.xlsx), Wide CSV, Narrow CSV, or TSV.
Ctrl + M Main Window Enables Marker Insertion mode for labeling events along the timeline.
Ctrl + 1 Main Window Switches immediately to the Spreadsheet tab.
Ctrl + 2 Main Window Switches immediately to the Trend Chart tab.
Ctrl + 3 Main Window Switches immediately to the Tags and Live Values tab.
Space Spreadsheet or Chart Toggles Auto-scroll (in spreadsheet) or Auto-follow (in chart).
Esc Main Window Cancels active marker placement mode.
Ctrl + Click OPC UA Node Tree Enables multi-selection of variable nodes for batch addition.
Delete Spreadsheet or Pen Panel Deletes the selected tag from collection.
Delete Connection List Deletes the selected OPC UA connection.
Mouse Wheel Trend Plot Performs horizontal Zoom In and Zoom Out along timeline.
Mouse Drag Spreadsheet Header Border Smoothly resizes the column header row height.

Health Metrics & Diagnostic Log

The bottom status bar exposes key indicators to verify system health in real-world plants:

  • Events per Second (Ev/s): instantaneous update frequency indicating OPC UA driver throughput.
  • Buffer Size: memory occupancy percentage in the zero-allocation circular buffer.
  • Session Duration: running chronometer tracking the duration of the current industrial run.
  • Operational Event Log: categorized log stream (Information, Warning, Error, Debug) with dedicated Clear and Log Folder… buttons.
