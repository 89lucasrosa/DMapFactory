Keyboard Shortcuts & Diagnostics

Productivity hotkeys, fast commands, and acquisition health monitoring

Global Keyboard Shortcuts Reference

Health Metrics & Diagnostic Log

The bottom status bar exposes key indicators to verify system health in real-world plants:

  • Events per Second (Ev/s): instantaneous update frequency indicating OPC UA driver throughput.
  • Buffer Size: memory occupancy percentage in the zero-allocation circular buffer.
  • Session Duration: running chronometer tracking the duration of the current industrial run.
  • Operational Event Log: categorized log stream (Information, Warning, Error, Debug) with dedicated Clear and Log Folder… buttons.

Log Severity Levels

Level Meaning When to Check / General Action
Information Normal operational events and user action audit trail. No corrective action required. Confirms that connections, Online/Offline transitions, markers, certificates, and exports completed successfully.
Warning Operational alerts, automatic reconnections, or partial conditions. Check network stability, verify that connections/tags exist before starting Online mode, or review certificate revocation/auto-accept settings.
Error Critical connectivity, PKI security, or disk I/O failures. Requires immediate attention: verify the OPC UA Endpoint URL, credentials, X.509 certificate trust/expiration, or folder write permissions.
Debug Detailed internal tracing (attribute reads, stack diagnostics). Used for engineering diagnostics. Keep unchecked during normal operation and enable the Debug filter when investigating specific OPC UA node behavior.

Complete Log Message Reference & Troubleshooting Guide

Below is the complete list of log messages emitted by DMapFactory, grouped by subsystem, including their explanation, what to check, and recommended corrective actions:

1. Startup, Project & Sessions

Level Log Message Pattern Explanation, What to Verify & Recommended Action
Information DMapFactory started. Ready to configure OPC UA connections. Explanation: Application initialized and acquisition engine ready.
Action: Add an OPC UA connection or open an existing project (Ctrl+O).
Information New project started. Explanation: Current workspace cleared to begin a fresh configuration.
Action: Configure connections and tags, then save with Ctrl+S.
Information Project loaded: '{path}' ({N} connections, {M} tags). Explanation: Project file (.dmproj) loaded successfully.
Action: Connect to your server or press F5 to start Online acquisition.
Error Failed to open project '{path}'. Explanation: The .dmproj file is corrupted, inaccessible, or contains invalid JSON.
Verify / Action: Check file permissions and verify the file was not manually edited with invalid JSON syntax.
Information Project saved to '{path}'. Explanation: All connections, tags, and sampling settings were saved to disk.
Action: No action required.
Error Failed to save project to '{path}'. Explanation: Disk I/O error while writing the project file.
Verify / Action: Check free disk space, folder write permissions, or whether the file is marked read-only.
Information Session loaded: '{name}' ({rows} rows, {tags} tags, {markers} markers). Explanation: Recorded session (.csv or .session.json) restored into the spreadsheet and trend chart.
Action: Use cursors A/B and search tools for offline analysis.
Error Failed to open session '{path}'. Explanation: The session file could not be parsed or accessed.
Verify / Action: Ensure the file is not locked exclusively by Excel and is a valid DMapFactory session file.
Information Sessions save location changed to: '{folder}'. Explanation: The directory where automatic Online session files are stored was updated.
Action: Subsequent Online sessions will be written to this folder.
Error Failed to configure/open sessions folder '{folder}': {error} Explanation: The configured session directory could not be created or opened.
Verify / Action: Use File > Configure sessions save location… and select a valid local folder with write access.
Error Failed to open logs folder '{folder}': {error} Explanation: Could not launch Windows Explorer for the logs directory.
Verify / Action: Check permissions on %LOCALAPPDATA%\DMapFactory\logs.
Information Interface language changed to '{language} ({culture})'. Explanation: UI and operational log language switched dynamically.
Action: No action required.

2. OPC UA Connectivity

Level Log Message Pattern Explanation, What to Verify & Recommended Action
Information Connection '{name}' ({endpoint}) added.
Connection '{name}' ({endpoint}) updated.
Connection '{name}' ({endpoint}) removed.		 Explanation: Audit record of adding, editing, or removing an OPC UA connection.
Action: Save the project (Ctrl+S) to persist changes.
Information [Connection] '{name}' ({endpoint}) CONNECTED successfully. Explanation: OPC UA session and secure channel established.
Action: Browse the OPC UA node tree or press F5 to start Online mode.
Error [Connection] Failed to connect to '{name}' ({endpoint}). Reason: {error} Explanation: Could not establish an OPC UA session with the server.
Verify / Action: 1) Verify IP/port reachability; 2) Check security policy and user credentials; 3) If the reason mentions BadCertificateUntrusted, open the Certificate Manager and trust the server certificate (and trust the client certificate on the PLC/server).
Information [Connection] '{name}' ({endpoint}) disconnected by user. Explanation: The operator intentionally clicked the Disconnect button.
Action: No action required.
Warning [Connection] '{name}' ({endpoint}) disconnected (closed by server or session ended). Explanation: The session closed without direct user request.
Verify / Action: Check if the OPC UA server/PLC restarted or if the session timeout expired.
Warning [Connection] '{name}' ({endpoint}) lost communication. Attempting automatic reconnection...
KeepAlive failed on {name}: {status}. Starting reconnection...		 Explanation: The OPC UA Keep-Alive request failed. The driver automatically started reconnecting.
Verify / Action: Check Ethernet cabling, industrial switches, and PLC CPU load. DMapFactory will automatically resume once the server responds.
Information Successfully reconnected to {name}. Explanation: The OPC UA session and subscriptions were automatically restored.
Action: No action required; live acquisition resumed automatically.
Error [Connection] '{name}' ({endpoint}) entered FAULTED state (connectivity error with OPC UA server). Explanation: The connection entered a faulted state after communication loss.
Verify / Action: Verify the OPC UA server is online and click Connect to re-establish the session.
Warning [Connectivity] {N} tag(s) from connection '{name}' assumed Bad status due to connection loss ({state}). Explanation: Because the connection dropped while Online, all associated tags were marked Bad and stopped plotting stale values on the chart.
Verify / Action: Restore the OPC UA connection so the tags return to Good status.
Information / Error [OPC UA Discovery] {N} endpoint(s) found at '{url}'.
[OPC UA Discovery] Failed to discover endpoints at '{url}': {error}
[Connection Test] Test succeeded for '{name}' ({url}).
[Connection Test] Failed to test connection '{name}' ({url}): {error}		 Explanation: Endpoint discovery and connection test results from the Connection Dialog.
Verify / Action: On failure, verify the opc.tcp://host:port syntax and firewall rules.

Action: Add at least one connection and add variables to the spreadsheet before pressing F5.
Warning [Online] Failed to auto-connect '{name}' while activating Online mode: {error} Explanation: When entering Online mode, DMapFactory attempted to connect a disconnected server automatically, which failed.
Verify / Action: Check the target server connectivity or remove unused connections.
Information [Online] ONLINE acquisition started ({N} tags, mode={mode}, rate={ms} ms). Recording session to '{file}'. Explanation: OPC UA subscriptions created and continuous session recording started.
Action: Monitor live data in the Spreadsheet or Trend Chart.
Information [Offline] OFFLINE acquisition stopped ({rows} rows collected, {markers} markers). Explanation: Live acquisition stopped and session files (.csv and .session.json) were finalized.
Action: Export the spreadsheet (Ctrl+E) or inspect the recorded history.
Error [Online/Offline] Error during acquisition state transition: {error} Explanation: An unexpected exception occurred while starting or stopping acquisition.
Verify / Action: Check write permissions on the sessions folder and verify server health.
Information Acquisition mode changed to '{mode}' (rate={ms} ms).
Timestamp source changed to '{source}'.		 Explanation: The operator changed the acquisition mode (Upon Change vs Sampling Rate) or timestamp source (Auto, Source/PLC, Server, or Local/OS).
Action: No action required; changes take effect immediately.
Information Subscription '{group}' started on '{conn}' ({ok}/{total} active tags).
Periodic acquisition '{group}' started on '{conn}' at fixed rate {ms} ms ({total} tags).		 Explanation: Confirms the acquisition engine started on the OPC UA server in the selected mode (Upon Change or Sampling Rate).
Action: No action required; verify {ok}/{total} matches the expected tags.
Warning MonitoredItem '{name}' ({nodeId}) returned status {status}.
OPC UA browse at {nodeId} returned status {status}.		 Explanation: The OPC UA server rejected or returned a bad status for a monitored item or node browse.
Verify / Action: Verify the NodeId exists on the PLC and the user has read permissions.
Warning / Error Error in polling loop for group {group}.
Failed to read initial tag snapshot on connection {conn}
Error stopping group {id} on driver {conn}
Failed to save/update/remove marker in session metadata
Error in session sample consumer loop		 Explanation: Failure during cyclic polling, group shutdown, or writing .session.json metadata.
Verify / Action: Check OPC UA connection stability and write permissions on the sessions folder.
Error / Debug Failed to browse OPC UA root: {error}
Failed to expand node {id}: {error}
Could not read attributes for {id}: {error}		 Explanation: The OPC UA server rejected browsing or attribute reading for a node.
Verify / Action: Check user permissions on the OPC UA server or verify the session is still connected.
Information / Warning Tag added: {alias} ({nodeId}) [{type}]
{N} tags batch-added to spreadsheet and chart.
Manual tag added: {alias} ({nodeId}) [{type}]
No variables found in the selected items to add.		 Explanation: Audit of tags added to collection or warning when a selected folder contains no variable nodes.
Action: Expand the folder in the browser tree to select Variable nodes.
Information [Tag] Tag renamed from '{old}' to '{new}' ({address}).
Tag removed from collection: '{alias}' ({address}).
All {N} tags were removed from collection.
Spreadsheet history cleared ({N} rows and {M} markers removed from view).		 Explanation: Audit trail for tag renaming, tag deletion, or clearing spreadsheet rows.

5. PKI Security Certificates (OPC UA X.509)

Level Log Message Pattern Explanation, What to Verify & Recommended Action
Warning / Information [Certificates] Auto-accept untrusted certificates ENABLED by user.
[Certificates] Auto-accept untrusted certificates DISABLED by user.		 Explanation: Changes the global server certificate validation policy.
Verify / Action: In production environments, keep auto-accept disabled and manually trust only verified PLC certificates.
Warning / Information [Certificates] Untrusted certificate auto-accepted (AutoAccept): Subject='{subject}', Thumbprint={thumb}
[Certificates] Certificate accepted by user and moved to Trusted: Subject='{subject}', Thumbprint={thumb}		 Explanation: An untrusted server certificate was accepted during connection.
Action: No action required.
Error [Certificates] Certificate rejected by user (stored in Rejected): Subject='{subject}', Thumbprint={thumb}, Reason={status} Explanation: The server certificate was untrusted and rejected. Connection was blocked.
Verify / Action: If rejected by mistake, open the Certificate Manager, select the certificate in Rejected status, and click Trust.
Information / Warning [Certificates] Server certificate marked as TRUSTED: Subject='{subject}', Thumbprint={thumb}
[Certificates] Server certificate marked as REJECTED: Subject='{subject}', Thumbprint={thumb}
[Certificates] Server certificate imported as trusted: ...
[Certificates] Server certificate exported: ...
[Certificates] Server certificate deleted from store: ...		 Explanation: Audit trail of server certificate operations in the PKI store.
Action: No action required.
Warning / Error [Certificates] Active connection '{name}' automatically disconnected because server certificate ({thumb}) was rejected/revoked.
[Certificates] Connection '{name}' automatically disconnected/blocked: server certificate '{subject}' ({thumb}) is EXPIRED (expired on {date}).		 Explanation: For security compliance, DMapFactory immediately terminates any active session whose server certificate is revoked or expired.
Verify / Action: Renew the expired X.509 certificate on the OPC UA server/PLC and trust the new certificate in the Certificate Manager.
Information / Warning / Error [Certificates] {N} server certificate(s) retrieved from '{url}' and saved to store.
[Certificates] No server certificates returned by endpoint '{url}'.
[Certificates] Failed to fetch server certificate from '{url}': {error}		 Explanation: Results of fetching server certificates via endpoint discovery.
Verify / Action: If no certificates are returned, verify the server has encrypted security policies enabled.
Information / Error [Certificates] New client certificate (Application Instance) generated: Subject='{subject}', Thumbprint={thumb}
[Certificates] Client public certificate exported (.der) to '{path}'.
[Certificates] Client certificate with private key exported (.pfx) to '{path}'.
[Certificates] Client certificate imported from '{path}': ...
[Certificates] Certificate operation failed ({op}): {error}		 Explanation: Audit trail for the DMapFactory client application certificate.
Verify / Action: Whenever generating or importing a new client certificate, export the public key (.der) and add it to the Trusted Clients list on the OPC UA server / PLC.
Warning Error disconnecting session {name} after certificate expiration. Explanation: The server certificate expired during an active session and an error occurred while closing the OPC UA connection.
Verify / Action: Renew the server certificate and reconnect manually.
