OPC UA Connections & Tag Browser

Server endpoint management, security policies, and industrial variable selection

Managing Connections

The top-left panel displays all configured OPC UA server endpoints in the current project.

How to Add a New Connection

  1. Click the Add Connection button (➕) on the toolbar or connection panel header.
  2. In the dialog, specify:
    • Connection Name: friendly label (e.g. PLC Line 1).
    • Endpoint URL: network address (e.g. opc.tcp://192.168.0.10:4840).
    • Security Mode: None, Sign, or SignAndEncrypt.
    • Security Policy: cryptographic suite (e.g. Basic256Sha256, Aes128_Sha256_RsaOaep).
    • Authentication: Anonymous or Username/Password credentials.
  3. Click Save to register the server in the project list.
💡 Credential Protection & Security Compliance (MG-04)
The connection setup dialog automatically secures authentication credentials behind masked password fields (PasswordBox), revealing user/password input rows only when the Username / Password mode is selected, ensuring strict industrial cybersecurity compliance.
💡 Connection Status Indicators
Each connection features a colored status dot:
  • Green: Connected and communicating normally.
  • Yellow: Connecting or in automatic reconnection retry.
  • Red: Connection fault or unreachable endpoint.

Sampling Rate & Acquisition Modes (FN-01)

The top toolbar provides immediate control over how DMapFactory polls or receives data from the OPC UA server:

  • Sampling Rate (10 ms to 1000 ms): adjusts the hardware inspection interval (e.g. 10 ms for high-speed servo positioning or 1000 ms for general thermal monitoring).
  • Subscription Mode: the default, recommended event-driven pattern where the server only transmits data packets when variable transitions occur (Report by Exception), optimizing network bandwidth.
  • Polling Mode: executes active cyclic batch reads at each elapsed interval, ensuring persistent data points on legacy servers with limited notification capabilities.

OPC UA Node Tree Browser

Selecting an active connection loads its address space in the OPC UA Browser tree.

Quick Node Search & Auto-Expansion (FN-03)

On servers hosting thousands of complex tags, locate variables immediately using the Search Box at the top of the node tree:

  • Type any substring of the display name or NodeId (e.g. Pressure, Sensor_12, ns=2;s=Motor).
  • The tree filters results in real-time, highlighting matches and automatically expanding parent folder containers.
  • Clicking the × button clears the search query and restores full tree visibility.

Adding Variables & Context Menu Actions

  • Single Tag: Select a variable node and click Add Selected Tag, double-click the item, or right-click and choose ➕ Add selected variable.
  • Multi-Selection with Ctrl: Hold down the Ctrl key while clicking multiple nodes in the tree to select them simultaneously, then click Add Selected Tag to batch-import all selected variables.
  • Entire Folder: Select a folder or object container and click Add Folder as Tags (or right-click → 📁 Add folder as tags) to recursively enroll all variables within it.
  • Copy NodeId: Right-click any node and choose 📋 Copy NodeId to copy the exact identifier string to the system clipboard.
🔍 Node Attributes Panel
Clicking any node in the tree immediately updates the lower Attributes panel, revealing its NodeId, data type (DataType: Boolean, Int32, Float, String, etc.), read/write permissions, and current live value.
