Trend Chart & Pen Panel

High-resolution time-series plotting engine with differential cursors and pen management

Real-Time Trend Charting Engine

The Chart tab renders real-time temporal curves for all monitored variables via the hardware-accelerated ScottPlot 5 engine, delivering 60 FPS plotting performance with minimal CPU footprint.

Navigation & Scaling Controls

Control Action Description
🔍+ / 🔍− Horizontal Zoom Shrinks or expands the displayed time span. You can also scroll the mouse wheel over the plot area.
↔ Fit All Autoscale Time Frames all data collected from the beginning of the acquisition session.
Y+ / Y− Vertical Scale Scales the vertical magnitude axis up or down.
Auto Y Reset Y-Scale Restores automatic vertical scaling adapted to the current min/max values of visible signals.
📷 PNG Snapshot Export Captures the current chart view directly to a high-resolution PNG image file.

Signal Curve Styling & Analysis Tools

  • Step Interpolation (Degrau): maintains value constant until next state transition, ideal for digital logic (0/1) and discrete states. Uncheck for linear analog curves (temperature, pressure, flow).
  • Sample Points (●): renders marker dots highlighting exact arrival timestamps for individual OPC UA events.
  • Crosshair: projects orthogonal guide lines and displays a floating HUD with the exact value of every pen under the mouse pointer.
  • A/B Cursors: activates two vertical measuring rulers. Drag them along the timeline to calculate differential time ($\Delta t$) and value delta ($\Delta Y$). Use Center A/B to reposition rulers into view.

High-Performance Charting Pipeline (PF-01, PF-07)

DMapFactory utilizes an optimized charting pipeline built on ScottPlot 5 with GPU/CPU accelerated rendering:

  • Peak-Preserving Adaptive Downsampling (PF-01): when plotting hundreds of thousands of data points, the adaptive downsampling engine clusters samples while strictly preserving local peaks and valleys (transient spikes, noise, and sharp edges), sustaining 60 FPS redraws with minimal memory overhead.
  • Binary Search Interpolation $O(\log N)$ (PF-07): signal readings for Cursors A/B and Crosshair HUD evaluate timestamps using binary search indexing, guaranteeing instantaneous lookups without stuttering even across millions of recorded points.

Chart Context Menu & Bidirectional Cross-Synchronization

Right-clicking anywhere on the plot surface opens a contextual menu with high-precision analytical actions:

Action Description
📊 Locate in Spreadsheet Bidirectional Chart → Spreadsheet Sync: instantly navigates the spreadsheet tab to the timestamp closest to the clicked chart point, highlighting the matching row and scrolling it into view.
📍 Position Cursor A here Immediately snaps measurement Cursor A (dashed yellow ruler) to the exact timestamp under the cursor.
📍 Position Cursor B here Immediately snaps measurement Cursor B (dashed cyan ruler) to the exact timestamp under the cursor.
🎯 Center Cursors A/B Positions both measurement rulers symmetrically in the current visible viewport.
🚩 Insert marker at this point... Opens a dialog to create an operational milestone event anchored to the clicked timestamp.
📷 Export Image (PNG)... Saves a crisp snapshot of the current view to an image file (Ctrl+P).

Pen Sidebar (Signals List)

Positioned on the right side of the chart, the Pen Panel manages curve visibility and individual signal properties:

  • Color Swatches: each pen shows its corresponding curve color.
  • Sky-Blue Selection Border: selecting any pen outlines it with a crisp sky-blue highlight (#00B4F0).
  • Direct Removal (×): each pen row contains a dedicated × button to instantly delete the tag from collection.
  • Pen Context Menu (Right-Click):
    • ⚙ Set as machine cycle trigger: binds the clicked boolean variable as the transition source for machine cycle tracking.
    • 📋 Copy NodeId: copies the full OPC UA identifier string to the system clipboard.
    • 🗑 Delete tag from collection: removes the variable from both spreadsheet and chart.
  • Batch Controls: click All to plot all signals, None to hide all, or × Delete to remove the active selection.
