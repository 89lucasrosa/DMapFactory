OPC UA Certificate Manager

Public Key Infrastructure (PKI), mutual trust validation, and secure channel encryption

OPC UA Security Principles

The OPC UA specification enforces point-to-point authentication and transport encryption via X.509 digital certificates. When connecting using secure profiles (Sign or SignAndEncrypt), mutual trust is mandatory:

  1. The Server must trust the DMapFactory (Client) certificate.
  2. The DMapFactory Client must trust the Server certificate.
⚠️ Common Failure: BadCertificateUntrusted
If connection negotiation fails with BadCertificateUntrusted or BadSecurityChecksFailed, either the DMapFactory public key has not been authorized in the server's trusted list, or the server's certificate has not yet been accepted into DMapFactory's trusted certificate store.

Accessing the Certificate Manager

Open the certificate management interface by clicking the Certificates button on the toolbar or via the menu: File > OPC UA Certificate Manager….

Available Management Operations

1. Application Client Certificate

  • Generate New Certificate: creates a fresh self-signed RSA 2048/4096-bit certificate with SHA-256 signature, embedding the local machine's ApplicationURI and DNS hostnames.
  • Export Public Certificate (.der / .cer): exports the public key file to copy and import into the server/PLC trusted client store.
  • Import Custom Certificate (.pfx / .p12): installs an enterprise PKI certificate issued by an internal corporate Certificate Authority (CA), complete with its private key and password.

2. Trusted Server Certificates

  • Import Server Certificate: imports public certificate files (.der or .cer) provided by the server or PLC vendor directly into DMapFactory's trusted store (trusted/certs).
  • Remove Certificate: revokes server trust when equipment is decommissioned or keys are rotated.
