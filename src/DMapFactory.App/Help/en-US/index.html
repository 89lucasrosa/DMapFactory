DMapFactory Overview

Industrial OPC UA Real-Time Data Acquisition, Analysis, and Visualization System

Software Introduction

DMapFactory is a high-performance desktop engineering tool designed for real-time monitoring, diagnostic analysis, and telemetry recording of industrial data via the OPC UA (Open Platform Communications Unified Architecture) protocol.

Built with .NET 10 and modern WPF, it pairs temporal precision sampling with dual synchronized visualization: Wide-Format Temporal Spreadsheet and Continuous Trend Charting.

💡 Context-Sensitive Help (F1)
At any moment while using the application, press F1 to immediately launch the exact help topic associated with the active screen, tab, or control you are working with.

Release Highlights & Productivity Enhancements

⚡ User Experience & High Performance
This release delivers a major architectural upgrade engineered for operational agility and responsiveness:
  • Global Keyboard Shortcuts: comprehensive keyboard control (Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+E, Ctrl+M, Ctrl+1/2/3, F5, Space, Esc).
  • Context Menus Across All Modules: right-click access across spreadsheet rows, headers, trend chart, OPC UA tree, pen list, and event log.
  • Bidirectional Cross-Synchronization: effortlessly locate timestamps from spreadsheet to chart, and vice-versa, with a single click.
  • Smart Auto-Scroll Pause: seamless manual scrolling for row inspection without disruptive auto-scroll jumps.
  • OPC UA Quick Node Search: high-speed text filtering with automatic folder hierarchy expansion.
  • Custom Machine Cycle Triggers: designate any boolean variable as a machine cycle trigger with automated $\Delta t$ and cycle index calculation.
  • Zero-GC Circular Buffer & Peak-Preserving Downsampling: rock-solid 60 FPS plotting and sub-millisecond query performance.

Operational Dashboard & Event Logging

The lower area of the application provides an integrated Status Bar and Event Log panel:

  • Online / Offline Status: displays live sampling state (Green = Online, Gray = Offline).
  • Connection Counter: number of active and healthy server connections.
  • Events/sec: instantaneous throughput of samples and value changes processed per second.
  • Buffer Size: current volume of samples stored in the internal circular memory ring.
  • Session Duration: running timer in HH:mm:ss format measuring acquisition elapsed time.
  • Active Cycle Indicator: tracks live machine operational cycles detected by the cycle trigger.
