What is the Purpose of the "Marker" Button?

During plant commissioning, recipe changeovers, conveyor performance tests, or machine trip investigations, engineers must correlate physical events observed on the plant floor with digital signals captured by the PLC.

The Marker button (flag icon 🚩 on the main toolbar) allows the operator to inject an immediate timestamped marker into the live acquisition stream.

📌 Marker Behavior
When triggering a Marker:
  • In Spreadsheet: the exact row corresponding to that timestamp is visually flagged in the marker column, spotlighting all tag values in that precise millisecond.
  • On Chart: a vertical dashed annotation line is drawn at that exact timestamp with the event description, allowing instant visual correlation of analog spikes or digital transitions.

Custom Machine Cycle Trigger (FN-02)

Beyond manual milestone markers, DMapFactory offers automated Machine Cycle Tracking driven by any digital PLC tag:

  • Zero-Friction Configuration: right-click any boolean tag in the spreadsheet or pen list and select ⚙ Set as machine cycle trigger.
  • Edge Detection: whenever the selected variable changes state (e.g., EndOfStroke_Sensor from 0 to 1), the acquisition engine registers the inception of a new machine cycle.
  • Automated Cycle Metrics: computes the exact cycle duration ($\Delta t$), increments the cycle index (e.g. #1, #2, #3), and displays the Active Cycle Indicator in the top header and within the spreadsheet Cycle column.

Automatic Marker Restoration on Loaded Sessions (MG-02)

When loading a previously recorded acquisition session (via File > Open Session... or shortcut Ctrl+O):

  • All historical event markers logged during the live run are fully restored.
  • Markers are seamlessly recreated on their corresponding spreadsheet rows and plotted as vertical annotation markers across the trend chart, providing post-mortem diagnostic fidelity.

Supported Data Export Formats

Using the Export Spreadsheet button or shortcut Ctrl+E, save your session data in any of the following standard formats:

  • Microsoft Excel Workbook (.xlsx): formatted workbook ready for management reports, pivot tables, and formulas.
  • Wide CSV (.csv): semicolon-delimited text with timestamps along rows and tags across columns (optimized for Power BI, Pandas, and Python analytics).
  • Narrow CSV (.csv): normalized key-value records (Timestamp, Tag, Value, Quality), ideal for SQL/NoSQL data lake pipelines.
  • Tab-Separated Values (TSV / Clipboard): rapid row copying to paste directly into spreadsheets without generating intermediate files.
  • Session Database (.db / SQLite): self-contained binary database ensuring complete audit trail traceability and permanent archival.
